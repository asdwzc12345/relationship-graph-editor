# 关系图编辑器

这是一个纯原生 Windows 桌面关系图编辑器。自 2.0 版起使用 C#、WinForms 和 GDI+：程序直接创建标准 Windows 窗口，不启动浏览器，不监听本地端口，也不加载 HTML、CSS 或 JavaScript 作为运行界面。

## 直接使用与分享

直接双击根目录中的 `关系图编辑器.exe` 即可运行。它是一个独立 EXE，可以单独复制给其他 Windows 用户，无需把项目文件夹一起发送。

运行环境：Windows 10 或 Windows 11，系统启用 .NET Framework 4.x。程序不会联网，关系图和自动恢复数据都保存在本机。

## 主要能力

- 主程序始终处于编辑状态，不提供仅查看模式；启动、新建或导入后可直接修改画布和右侧属性。
- 单击节点、分组或关系可高亮真实相邻关系；可选择上游、下游或双向，并查看 1～3 层。
- 单击节点时，全图文字完全相同的节点会联动高亮，并以这些同名节点为共同起点合并显示邻居；选择上游或下游时，没有对应方向连线的同名节点会变暗，包括实际点击的节点。
- 实际点击的节点即使因方向规则变暗，仍保留选中边框与唯一逻辑选中状态；双向模式显示全部完全同名节点。
- 同名高亮只影响显示与邻居计算，逻辑上仍只选中实际点击节点，因此移动、删除和属性编辑不会误作用于其他同名节点。
- 编辑模式下右侧属性不再需要“应用修改”：输入内容会立即反映，并在短暂停顿或离开输入框后自动保存。
- 节点“颜色分类”同时显示真实色块和简洁颜色文字，例如“蓝色”。
- 界面主题支持跟随系统、浅色和深色三档；默认跟随 Windows 应用主题并自动响应系统变化。
- EXE 文件、Windows 任务栏、主窗口和程序弹窗统一使用内嵌的 `app-icon.ico`，无需携带外部图标文件。
- 编辑模式下，已选节点或分组可拖动；拖动未选节点或分组可创建关系。
- 节点和分组接近其他节点或分组的左边、中心、右边或上下边界时会互相对齐，并显示横向或纵向参考线；多选节点按整体边界对齐。
- 节点或分组接近一行或一列中另外两个对象的等间距位置时，会自动吸附，并显示两段同长度标记及“等距”数值提示；三者可由节点和分组混合组成。
- 按住 `Ctrl` 再拖动节点或分组，可临时关闭网格、对齐和等间距吸附，自由摆放。
- 节点和分组选中时均不显示连线圆圈；拖动未选中的对象完成连接后，会依据两个对象的最终相对位置自动使用上、右、下、左端口。
- 分组选中后可移动；鼠标移到四条边或四角时会显示对应方向的缩放光标，拖动即可调整大小。
- 节点的所属分组由空间位置自动匹配，可同时属于多个相互嵌套或重叠的分组；右侧以只读路径展示，不允许手工修改。
- 分组完整位于另一个分组内时会自动成为子分组，支持任意多层嵌套；移动外层分组时，内部子分组和节点会同步移动。
- 分组按面积从大到小绘制：大分组始终位于底层，小分组覆盖在其上，节点始终位于所有分组之上；重叠位置点击也遵循相同优先级。
- 节点也可以不属于任何分组，关系仍可连接节点或分组。
- 新关系可选择曲线、直线或折线，关系名称允许留空。
- 每条线的颜色由起点节点的颜色分类实时决定；修改起点颜色后，所有出线立即同步。分组作为起点时使用分组边框色。
- 编辑模式下双击画布空白位置，可直接在该位置生成新节点；位于分组内时会自动归组。
- 双击节点左上角类型、节点中央名称或分组左上角标题，可直接在画布内编辑；这些文字区域不会被识别为空白位置。
- 删除选中项立即执行，可使用撤销恢复；右键清除当前全部选择。
- 支持左键同时框选节点和分组；混合选择可整体移动、复制粘贴或删除，且不会自动高亮邻居。
- 框选或选中节点、分组后点击“＋分组”，程序会按全部选中内容的整体边界自动创建大小合适的外层分组，并预留标题区和四周边距；选中的已有分组会自动成为新分组的子分组。
- 撤销和重做只恢复关系图内容，保持当前画布缩放比例和视野位置不变。
- 支持多选、复制粘贴、撤销、重做、查找、缩放和右键平移。
- 画布不受默认尺寸边界限制，可向任意方向平移、创建和摆放节点或分组；“适合窗口”和所有图形导出会自动取当前全部内容范围。
- 新建、恢复默认、导入或关闭前会保护尚未写入 JSON 的修改，可选择保存、不保存或取消操作。
- JSON 与所有导出文件采用同目录原子写入；再次保存 JSON 时保留上一版 `.bak`，写入中断不会破坏原文件。
- 自动恢复主文件位于 `%LocalAppData%\Relationship Studio\autosave-native.json`，同时保留 `.bak` 和最多 10 个节流历史版本；主文件损坏时会依次尝试恢复。

## 文件兼容

可导入：

- 本工具的 JSON 关系图；
- 旧版和 2.0 版导出的只读 HTML 可视图。

可导出：

- JSON：可继续编辑的数据文件；
- 飞书画板文件（`.drawio`）：在飞书桌面端画板中导入后，节点、分组和连线均为独立可编辑对象，每个节点可单独移动；
- 只读 HTML：用于分享和交互浏览，支持跟随系统/浅色/深色主题、显示或隐藏连线、左键点击对象查看相关关系、右键清除或拖动画布、滚轮和按钮缩放，也可重新导入本工具；
- SVG、PNG 和 PDF；PDF 使用矢量图形和文字轮廓，放大后仍保持清晰。

HTML 在 2.0 中只是一种可选的分享文件格式，不再是软件的运行底层。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 移动节点或分组 | 编辑模式下先单击选择，再拖动；所属层级按新位置自动匹配，移动外层分组会带动内部子分组和节点；按住 `Ctrl` 拖动可自由摆放 |
| 快速新增节点 | 编辑模式下双击画布空白位置 |
| 为选中内容增加分组 | 先框选或多选节点、分组，再点击“＋分组”；新分组会自动包住全部选中内容并保留合适边距 |
| 屏幕中心新增节点 | 点击“＋节点”，节点中心会落在当前画布视野中心；中心位于分组内时自动归组 |
| 屏幕中心新增空分组 | 没有选中节点或分组时点击“＋分组”，分组中心会落在当前画布视野中心 |
| 编辑节点类型 | 双击节点左上角类型角标 |
| 编辑节点名称 | 双击节点中央名称 |
| 查看同名节点关系 | 单击任意节点；同名节点按当前方向联动显示，上游/下游模式会将没有对应方向连线的节点变暗，实际点击节点仍保持逻辑选中，内部邻居计算不变 |
| 使用只读 HTML | 顶部可选择跟随系统、浅色或深色主题，可开关连线并选择关系方向和层数；左键点击对象高亮，右键单击清除，右键拖动画布，滚轮或“＋/－”缩放 |
| 编辑分组名称 | 双击分组左上角标题 |
| 查看所属分组 | 选择节点或分组后，在右侧查看自动匹配的只读多层路径，例如“菜单 > 菜单主题” |
| 编辑关系名称 | 双击线条；可修改或清空名称，`Enter`/失焦保存，`Esc` 取消 |
| 创建关系 | 编辑模式下直接拖动一个未选对象到另一对象 |
| 节点或分组连线 | 拖动未选中的对象到目标，程序依据两个对象的最终相对位置自动选择上、右、下、左端口；选中时不显示连线圆圈 |
| 调整分组大小 | 选择分组后，将鼠标移到任意边缘或四角，光标变化后拖动 |
| 多选节点 | `Ctrl` 或 `Shift` + 单击 |
| 框选节点和分组 | 编辑模式下，按住左键拖动画布空白处；节点与完整位于框内的分组会同时选中，多选时不会自动高亮邻居 |
| 复制 / 粘贴选中内容 | `Ctrl+C` / `Ctrl+V`；复制内部关系，粘贴内容的整体中心落在当前画布视野中心 |
| 清除选择 | 右键或 `Esc` |
| 平移整个画布 | 按住右键拖动，拖动期间显示十字光标 |
| 显示全部内容 | 点击“适合窗口”或按 `Ctrl+0`，自动取所有节点、分组和连线范围 |
| 导入飞书画板 | 选择“文件 → 导出 → 飞书画板（draw.io，可编辑）”，再在飞书桌面端画板中导入生成的 `.drawio` 文件 |
| 删除选中对象 | 画布未在输入文字时按 `Delete`；`Backspace` 只用于文字回退 |
| 缩放 | 鼠标滚轮，或工具栏 `＋` / `－` |
| 调整界面明暗 | 工具栏“主题”，或“视图 → 界面主题” |
| 平移画布 | 按住右键拖动 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 导入 | `Ctrl+O` |
| 保存 JSON | `Ctrl+S` |
| 查找 | `Ctrl+F` |

## 构建

在项目目录运行：

```powershell
npm run build:desktop
```

构建脚本调用 Windows 自带的 C# 编译器，将 `native` 目录中的全部 C# 源码、根目录的默认关系图和程序图标打包为根目录下的单个 `关系图编辑器.exe`。构建会嵌入 `desktop/app.manifest`，声明 Windows 10/11 兼容性和 Per-Monitor V2，并启用 WinForms 的 DPI 自动缩放基础设置；正式发布前仍应在不同缩放比例的多显示器环境中验证动态缩放。默认构建不签名。

发布时可选用 Windows 证书存储中的代码签名证书。传入 SHA-1 证书指纹后，脚本才会查找 `signtool.exe`、签名并验证结果；时间戳地址可以替换或留空：

```powershell
powershell -ExecutionPolicy Bypass -File desktop/build-desktop.ps1 `
  -CertificateThumbprint "你的证书指纹" `
  -TimestampUrl "https://timestamp.digicert.com"
```

证书位于本机计算机证书存储时追加 `-UseMachineCertificateStore`；Windows SDK 不在常规位置时可传入 `-SignToolPath`。仓库不附带证书，也不会伪造或自动申请签名。

运行完整原生自检：

```powershell
npm test
```

自检会重新构建 EXE，将它复制到一个隔离的临时文件夹中运行，并验证默认图、JSON 往返、原子保存与恢复、只读可视图导入、SVG/PNG/矢量 PDF 输出、画布交互以及单文件独立性。

只运行不覆盖 EXE 的原生静态审计：

```powershell
npm run audit
```

## 原生源码结构

- `native/GraphModel.cs`：数据模型、校验、JSON 与只读文件导入。
- `native/GraphCanvas.cs`：GDI+ 画布、绘制、命中检测和鼠标交互。
- `native/MainForm.cs`：标准桌面菜单、工具栏、属性面板和文件操作。
- `native/GraphHistory.cs`：有数量和内存预算的撤销/重做快照。
- `native/NativePersistence.cs`：原子写入、备份和滚动自动恢复。
- `native/NativeExport.cs` 与 `native/NativePdfExport.cs`：飞书画板、只读 HTML、SVG、PNG、矢量 PDF 和 JSON 导出。
- `native/Program.cs`：程序入口、版本信息和独立自检。
- `desktop/build-desktop.ps1`：单 EXE 构建脚本。
- `desktop/app.manifest`：高 DPI、Windows 兼容性和执行权限声明。
- `system-function-graph.json`：原生默认图的唯一数据源。
- `tools/test-native-desktop.mjs`：原生静态约束与独立 EXE 自检入口。

## 旧网页版本

历史网页实现、旧浏览器启动器、专属检查和测试样例统一位于 `legacy-web/`，不参与当前原生发布。它仍可作为普通静态网页打开；根目录的 `system-function-graph.json` 仍是默认图的唯一数据源，修改后运行 `npm run legacy:sync-default` 重新生成旧网页使用的数据镜像。

旧版检查全部使用 `legacy:*` 命名，例如 `npm run legacy:audit`、`npm run legacy:audit:routing` 和 `npm run legacy:test:store`，不会被默认的 `npm test` 或 `npm run audit` 调用。

当前版本：`4.4.0`。
